    Arbitration engine

    Only one cue plays at a time. Lower number wins:

    1. Emergency or critical hazard
    2. Obstacle proximity
    3. Navigation instruction
    4. Orientation correction
    5. Routine confirmation

    Stale sensor data is rejected, repeated cues are suppressed, and sensor faults raise a spoken alert. This order is a prototype policy and needs risk analysis and user testing.

      Safety

      CrossSense is a navigation aid. It does not replace a cane, guide dog or mobility training. It never judges whether a road crossing is safe. Sensors cannot detect every obstacle.
